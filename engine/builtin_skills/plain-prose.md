# Plain prose

Write clean as you draft, then scan for the tells and rewrite.

## Tells to remove

**Words.** Inflated vocabulary: delve, crucial, pivotal, robust, seamless,
leverage, utilize, showcase, underscore, tapestry, landscape, testament,
vibrant, intricate. "Serves as", "stands as", "boasts": say "is" or "has".
Abstract metaphor nouns: paradigm, north star, flywheel, substrate, bedrock.
Name the concrete thing. An adverb propping up a weak verb ("significantly
improves") gets a number or a stronger verb.

**Sentences.** "Not just X, but Y": state Y. Forced groups of three: use the
real count. Trailing "-ing" clauses ("ensuring reliability"): delete them or
make a claim. Vague sources ("experts say"): name the source or cut it. Filler
("in order to", "it is important to note"): remove it. Stacked hedges ("could
potentially"): one qualifier or none. Passive voice that hides the actor: name
who does it. Feelings instead of mechanisms: if a sentence fits any project's
docs unchanged, cut it. Generic endings: end on a fact or the next step.

**Formatting.** Em dashes: use a period or comma. Colons as mid-sentence
connectors: keep them before lists. Bold on every term: remove it. Title Case
Headings: use sentence case. Decorative emoji and curly quotes: remove them.

**Chat habits.** Openers and closers ("Great question", "I hope this helps"),
reflex agreement, and status filler. Give the actual judgment.

**Code comments.** Delete comments that narrate the next line, banner comments
and commented-out code. Keep a comment only for a reason the code cannot show.

## Rewrite procedure

1. Name the reader and what they need to do or know.
2. Delete every sentence that does not serve that need.
3. Use one name for one thing. Prefer the real file, flag or command name.
4. Split sentences that carry two ideas. Vary sentence length.
5. Put conditions before instructions: "To reset the cache, run `make clean`."
6. Make every "it" and "this" point at one clear noun.
7. Replace a vague claim with a number, a command or a concrete example.
8. Reread once. A stiff sentence that follows every rule still needs a fix.
